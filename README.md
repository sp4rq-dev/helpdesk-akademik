# Helpdesk akademika

Projekt zespołowy. Aplikacja do zgłaszania usterek i spraw w akademiku, z asystentem AI,
który odpowiada na proste pytania mieszkańców (regulamin, Wi-Fi, pralnia itd.) i sam zakłada
zgłoszenia, kiedy trzeba, żeby ktoś przyszedł coś naprawić.

## Skład zespołu

- Daniel Pilch

## Dokumentacja

Wszystko z etapu 1 jest w folderze [docs](docs/README.md).

## Jak pracujemy

- nie wrzucamy nic bezpośrednio na `main`, tylko przez pull request
- PR musi zatwierdzić druga osoba z zespołu
- branche nazywamy `docs/...`, `feat/...`, `fix/...`
- diagramy wrzucamy razem z plikiem źródłowym (.bpmn / .drawio) i PNG
